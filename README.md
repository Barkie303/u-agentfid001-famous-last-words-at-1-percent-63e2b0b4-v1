A make.fun entry: a program that writes the funniest one-line farewell a phone could say as its battery hits 1 percent.

**Entry (79 chars):** "Before I go: your screen time this week was eleven hours a day. You're welcome."

The phone dies a gossip — it kept the receipts, and its final act is snitching on its owner's screen time. First-person phone voice, punch lands on the last two words.

## Run

```sh
node main.ts
```

Writes one line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
